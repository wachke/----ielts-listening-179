# 雅思听力 179 考点同义替换词记忆神器 🎧

> 基于《剑桥雅思真题听力考点词》整理，收录全部 179 组高频考点词及常用替换词，支持手机/电脑端免安装离线背诵与刷题测试。

🔗 **在线体验网址**：[https://wachkewa.github.io/ielts-listening-179/](https://wachkewa.github.io/ielts-listening-179/)

---

### ✨ 核心功能

* 📇 **智能抽认卡 (Flashcards)**：双面翻转、国际音标、原声朗读磨耳，支持「已掌握 / 模糊 / 不认识」记忆反馈与快捷键操作。
* 📑 **同义替换速查词表 (Table)**：五列完整对照，全部常用替换词均配有精准中文释义，支持毫秒级中英文实时检索。
* 📝 **真题同义替换速测 (Quiz)**：听力仿真选择题，答错自动收录进本地错题本，提供连胜激励。
* 🎮 **消消乐连连看 (Match Game)**：考点词与听力替换词配对消除，强化听力瞬间反应速度。
* 📊 **本地数据持久化**：学习进度、掌握状态与生词本自动保存在浏览器本地（LocalStorage），零服务器依赖。
